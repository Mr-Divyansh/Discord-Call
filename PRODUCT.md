# Product Brief — CallFrame

**Created by Divyansh — DVF Studio**

## One-line description
CallFrame turns prerecorded two-person audio into a rendered Discord-inspired voice-call video.

## Problem
Creators often need a convincing voice-call scene but do not want to arrange a live call, record their screen, or manually animate every speaking indicator.

## Solution
A simple editor where creators upload two participant tracks, profile pictures, and call sound effects, preview the scene, and render a synchronized MP4.

## Main value
**Upload the audio. Assign the participants. Preview the call. Render the video.**

## Primary user
A gaming or storytelling creator who already has recorded dialogue and needs a call-style visual for a video.

## MVP promise
- Two participant tracks.
- Custom avatars and display names.
- Ringing, connected, and ended states.
- Automatic green speaking rings.
- Original pauses preserved.
- Local render to MP4.
- No live Discord call required.

## Success measures
- A new user can configure a basic project without developer help.
- The output is synchronized and playable.
- The active speaker indicator matches the correct track.
- A render can be cancelled without damaging the project.
- A clean install works using the published documentation.

## Constraints
- Rendering performance depends on local hardware.
- High resolution and high FPS increase render time and storage use.
- Exact stack and packaging method remain implementation decisions.
- “180 PM” must be clarified before it becomes a requirement.
